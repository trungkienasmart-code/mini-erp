Kết nối API báo tiền về tự động
Tính năng nâng cao (tùy chọn): Tự động nhận thông báo khi có tiền CK về → hệ thống tự khớp đơn hàng. Cần đăng ký dịch vụ Casso/Sepay (phí ~150-200k/tháng). Nếu không dùng → bỏ qua phần này, POS vẫn hoạt động bình thường.
Dùng để verify chữ ký webhook
Dán URL này vào phần "Webhook URL" trong tài khoản Casso/Sepay của bạn.
Hướng dẫn kết nối Casso (5 phút)
  1. Đăng ký tài khoản Casso: Truy cập casso.vn → Đăng ký (có bản dùng thử 7 ngày).
  2. Liên kết ngân hàng: Trong Casso, chọn "Liên kết ngân hàng" → chọn ngân hàng của bạn → đăng nhập Internet Banking → cấp quyền.
  3. Lấy API Key: Vào "Cài đặt" → "API" → copy "API Key" và "Secret Key".
  4. Dán vào Mini ERP: Ở form bên trên → paste API Key + Secret Key → bật "Nhận webhook" → Lưu.
  5. Đăng ký Webhook URL trong Casso: Vào "Webhook" trong Casso → dán URL ở trên → chọn sự kiện "Giao dịch tiền vào" → Save.
  6. Test: Thử CK 10,000đ vào STK đã liên kết với nội dung "Test" → trong 30 giây, Casso sẽ gọi webhook của Mini ERP.
Lưu ý: Mini ERP cần có URL public (VD: https://abc.trycloudflare.com) để Casso gọi webhook được. Xem hướng dẫn cài Cloudflare Tunnel ở tab Mạng LAN.
